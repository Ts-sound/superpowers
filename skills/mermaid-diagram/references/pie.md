# Pie Chart Detailed Syntax

## Basic Syntax

```mermaid
pie title Chart Title
    "Category A" : 35
    "Category B" : 25
    "Category C" : 40
```

## Complete Examples

### Programming Language Usage

```mermaid
pie title Programming Language Usage
    "JavaScript" : 35
    "Python" : 25
    "Java" : 20
    "C++" : 15
    "Other" : 5
```

### Weekly Time Allocation

```mermaid
pie title Weekly Work Time Allocation
    "Development" : 25
    "Meetings" : 10
    "Documentation" : 5
    "Code Review" : 5
    "Learning" : 5
```

### Sales by Product Line

```mermaid
pie title Sales by Product Line
    "Product A" : 45000
    "Product B" : 32000
    "Product C" : 23000
    "Product D" : 18000
```

## Notes

1. Values are automatically converted to percentages
2. Use double quotes for labels
3. At least 2 data items required

## Common Use Cases

1. **Market share** - Competitor proportions
2. **Budget allocation** - Department/project budget ratios
3. **Time allocation** - Activity time proportions
4. **Survey results** - Response option proportions
