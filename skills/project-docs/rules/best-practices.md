# Best Practices & Anti-Patterns

最佳实践与反模式，按需调用。

## 最佳实践

1. **设计与计划分离** — `docs/design/` vs `docs/plans/`
2. **图表优先** — 能用 mermaid 表达的架构/流程，优先用图表
3. **模块短名** — `auth/` 而非 `authentication/`
4. **同步更新** — 设计文档必须反映当前代码状态
5. **交叉引用** — 相关文档之间互相链接
6. **双语 README** — 主文档 + 本地化版本，提供切换链接
7. **AGENTS.md** — 定义 AI 协作约定

## 反模式（禁止行为）

- 在设计文档中写入实现细节（属于 plans 范畴）
- 设计文档缺少必要的 mermaid 图表
- 设计文档与代码实现长期不一致
- 使用冗长的模块目录名称
